How are you playing?
Settings +

One-block grace pairs nearby blocks one-to-one. One drawn block cannot match several reference blocks.

Play locally, with no accounts or connection required. In a duel, pass the screen between players. Practice is a solo memory challenge.

Both players get the same drawing window. After each has taken one attacking turn, the round ends and the window gets shorter, down to your chosen minimum.

Results appear after both drawings. Erase or undo to return blocks to your pixel budget.
